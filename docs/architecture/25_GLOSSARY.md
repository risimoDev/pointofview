# 25. Глоссарий

**Статус документа:** справочник, создан 2026-07-16 по итогам [REVIEW_BOARD.md](REVIEW_BOARD.md)
**Аудитория:** все читатели корпуса
**Закрывает находку:** B-64
**Назначение:** единственное место определения терминов. При расхождении термина в других документах с этим — приоритет за этим документом.

---

## Как пользоваться

Термины сгруппированы по областям. Внутри — по алфавиту. Для каждого: определение, а где полезно — где он встречается в коде и в каком документе разобран.

Пометки статуса реализации в определениях: **[есть]** — в коде; **[план]** — спроектировано, не реализовано.

## 1. Доменные сущности

**Тенант (tenant)** — организация-клиент платформы. Единица изоляции данных и тарификации. `tenant_id` из JWT фильтрует каждый запрос. Таблица `tenant`. Не путать с площадкой: у тенанта может быть много площадок. **[есть]**

**Площадка (site)** — физический объект наблюдения: один ПВЗ, один цех, один офис. Несёт часовой пояс (`site.timezone`), к которому привязаны расписания и время в уведомлениях. Единица тарификации для ПВЗ. Таблица `site`. Разобрано: [00](00_VISION.md), [21](21_TENANT_LIFECYCLE.md). **[есть]**

**Камера (camera)** — источник видео на площадке. Имеет два адреса: `url_sub` (субпоток для ИИ и живого видео) и `url_main` (основной поток для архива). Таблица `camera`. Разобрано: [05](05_CAMERA_CONNECTION.md). **[есть]**

**Зона (zone)** — область кадра (полигон в нормализованных координатах 0..1) с типом (`kind`) и правилами. Основа геофенсинга. Таблица `zone`. Разобрано: [08](08_RULE_ENGINE.md). **[есть]**

**Событие (event)** — единица ценности платформы. Факт, зафиксированный аналитикой: вход в зону, очередь, нарушение, скопление. Хранится в гипертаблице `event`. «Событие важнее кадра» — [00](00_VISION.md), 11.1. Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), [10](10_DATABASE.md). **[есть]**

**Модуль / фича (feature)** — включаемая по тенанту функциональность (`ppe`, `reid`, `shelf`, ...). Основа тарифной упаковки. Таблица `tenant_feature`. Не всякий модуль реализован как плагин ([07](07_PLUGIN_SYSTEM.md), 5.3). **[частично]**

**Правило зоны** — логика уровня анализатора, решающая, произошло ли событие. Живёт в `ZoneEngine`. Разобрано: [08](08_RULE_ENGINE.md), 3. **[есть]**

**Правило алерта (alert_rule)** — логика уровня API, решающая, сообщить ли о событии. Таблица `alert_rule`. Разобрано: [08](08_RULE_ENGINE.md), 5. **[есть]**

## 2. Компьютерное зрение и ИИ

**Детекция** — нахождение объекта (человека) на кадре. YOLOv8, только класс `person` (COCO 0). Разобрано: [06](06_AI_ENGINE.md), 3. **[есть]**

**Трек (track) / трекинг** — связывание детекций одного объекта между кадрами. ByteTrack. `track_id` — идентификатор трека, нестабилен при потере объекта. Разобрано: [06](06_AI_ENGINE.md), 4. **[есть]**

**Re-ID (повторная идентификация)** — присвоение человеку `global_id`, стабильного между камерами площадки. Без биометрии, по одежде/силуэту. Разобрано: [06](06_AI_ENGINE.md), 5. **[есть]**

**global_id** — идентификатор личности (Re-ID). Переживает смену `track_id`. Ключ состояния зон и кулдауна алертов. Анонимен сам по себе; становится ПДн при связывании с личностью ([23](23_ENTERPRISE_INTEGRATION.md), 8.2). Хранится в галерее с TTL 12ч. **[есть]**

**Эмбеддинг (embedding)** — числовой вектор внешности. HSV-гистограмма (384 измерения) или OSNet ONNX. Сравнивается косинусной близостью. Разобрано: [06](06_AI_ENGINE.md), 5.2. **[есть]**

**Галерея (gallery)** — набор эмбеддингов известных личностей. Посетители: `reid:gallery:{site_id}`, TTL 12ч. Сотрудники: `reid:staff:{tenant_id}`, бессрочно. **[есть]**

**Пробация (probation)** — период накопления доказательств до создания новой личности (`min_samples=3`, `min_track_age=3с`). Следствие инцидента «2 курьера = 44 посетителя». Разобрано: [06](06_AI_ENGINE.md), 5.4. **[есть]**

**Dwell (время пребывания)** — сколько человек находится в зоне. Основа `queue_alert` и метрик очереди. `meta.dwell_sec`. Разобрано: [08](08_RULE_ENGINE.md), [15](15_PVZ_MODULES.md). **[есть]**

**Геофенсинг** — определение принадлежности точки полигону зоны (трассировка луча). `ZoneEngine._point_in_polygon`. **[есть]**

**Занятость (occupancy)** — текущее число людей. Метрика, не событие. `occupancy:{tenant_id}`. **[есть]**

**Плагин (FeaturePlugin)** — модуль отраслевой логики, обрабатывающий кадр. Сегодня — класс в кодовой базе, не динамически загружаемый модуль. Разобрано: [07](07_PLUGIN_SYSTEM.md). **[есть]**

**Батчинг инференса** — подача нескольких кадров в модель за один вызов. Главный неиспользованный рычаг ёмкости GPU. Разобрано: [06](06_AI_ENGINE.md), [20](20_SCALE_ARCHITECTURE.md), 8. **[план]**

**Реестр моделей** — версионированный каталог моделей ИИ с привязкой «какая модель породила событие». Разобрано: [06](06_AI_ENGINE.md). **[план]**

**Дрейф (drift)** — деградация точности модели со временем (сезон, освещение, новая спецодежда). Разобрано: [06](06_AI_ENGINE.md). **[план]**

**Теневой прогон (shadow)** — исполнение новой модели параллельно рабочей без влияния на результат, для сравнения. **[план]**

## 3. Архитектура и потоки

**Analyzer** — единственный Python-сервис. Приём RTSP, детекция, трекинг, Re-ID, зоны, плагины. Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), 4. **[есть]**

**Recorder** — сервис записи видеоархива (ffmpeg `-c copy`, основной поток). Отдельный профиль compose. **[есть]**

**Redis Stream** — транспорт межсервисных сообщений с consumer group. Стримы: `track_events` (телеметрия), `events` (события), `events:failed` (dead-letter). Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), 9.1. **[есть]**

**Проекция (projection)** — данные PostgreSQL, скопированные в Redis для анализатора (`cameras:`, `zones:`, `features:`). Analyzer не ходит в БД (A-03), читает проекцию. Рассинхрон чинится «Ресинхр Redis». **[есть]**

**Dead-letter** — очередь для сообщений, которые не удалось обработать (`events:failed`). Сообщение подтверждается (XACK), чтобы не блокировать группу. Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), 6.3. **[есть]**

**Heartbeat** — периодический сигнал жизни камеры (`camera_alive:{id}`, TTL 15с). Отсутствие → камера офлайн. Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), 11.4. **[есть]**

**Watchdog** — процесс, реагирующий на отсутствие сигнала. Камер: `camera_watchdog` (300с → `camera_offline`). Туннеля: `wg-watchdog.sh`. **[есть]**

**Reconciler** — процесс, восстанавливающий состояние внешнего компонента. go2rtc теряет потоки при рестарте; reconciler их восстанавливает (60с). **[есть]**

**BullMQ** — очередь заданий поверх Redis. Очереди `clips`, `alerts`. **[есть]**

**go2rtc** — прокси RTSP→MSE/HLS для живого видео в браузере. Один экземпляр, host network. Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), [05](05_CAMERA_CONNECTION.md). **[есть]**

**Тикет WebSocket (ws_ticket)** — одноразовый токен для аутентификации WS-соединения (JWT в query попал бы в логи). `GETDEL`. Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), 6.4. **[есть]**

## 4. Масштаб (планка 1000+)

**Ячейка (cell)** — самодостаточный экземпляр платформы на подмножество тенантов. Единица радиуса поражения, выката, резидентности. Разобрано: [20](20_SCALE_ARCHITECTURE.md), 3. **[план]**

**Control plane** — глобальный слой над ячейками: реестр тенантов, роутинг, провижининг, метеринг. Вне горячего пути. Разобрано: [20](20_SCALE_ARCHITECTURE.md), 4. **[план]**

**Data plane** — сами ячейки, обслуживающие трафик клиентов. Противопоставление control plane. **[план]**

**Роутер (router)** — компонент control plane, направляющий запрос в ячейку тенанта. Обязан оставаться простейшим сервисом. Разобрано: [20](20_SCALE_ARCHITECTURE.md), 5.2. **[план]**

**Радиус поражения (blast radius)** — множество клиентов, затронутых одним отказом. Сейчас — все; цель — ячейка. Разобрано: [20](20_SCALE_ARCHITECTURE.md), 5; [11](11_HIGH_AVAILABILITY.md). **[план]**

**Шумный сосед (noisy neighbor)** — тенант, потребляющий сверх доли и вредящий соседям. Сдерживается квотами и сбросом нагрузки. Разобрано: [20](20_SCALE_ARCHITECTURE.md), 7. **[план]**

**Сброс нагрузки (load shedding)** — сознательное снижение качества при перегрузке вместо отставания от реального времени (рост `frame_skip`, не выше 3). Разобрано: [20](20_SCALE_ARCHITECTURE.md), 7.3. **[план]**

**Admission control** — отказ в приёме камеры, превышающей ёмкость ячейки. **[план]**

**Brownout** — режим частичной деградации (жёлтый/оранжевый/красный/чёрный). Разобрано: [20](20_SCALE_ARCHITECTURE.md), 7.4. **[план]**

**Квота (quota)** — лимит тенанта (камеры, пользователи, API rps, `gpu_share`). Разобрано: [21](21_TENANT_LIFECYCLE.md), 4. **[план]**

**Честная доля (fair share)** — доля ресурса ячейки, гарантированная тенанту по тарифу; превышение допустимо при отсутствии перегрузки. Разобрано: [21](21_TENANT_LIFECYCLE.md), 4.3. **[план]**

**Консистентное хеширование** — распределение камер по процессам пула анализаторов. Разобрано: [20](20_SCALE_ARCHITECTURE.md), 6.2. **[план]**

## 5. Жизненный цикл и эксплуатация

**Провижининг (provisioning)** — создание тенанта: реестр, ячейка, хранилище, биллинг. Реализуется как сага. Разобрано: [21](21_TENANT_LIFECYCLE.md), 7. **[план]**

**Метеринг (metering)** — учёт потребления для тарификации. Идемпотентен, принимает опоздавшие записи. Разобрано: [21](21_TENANT_LIFECYCLE.md), 5. **[план]**

**Офбординг (offboarding)** — вывод клиента: экспорт, карантин 30 дней, удаление, акт. Разобрано: [21](21_TENANT_LIFECYCLE.md), 9. **[план]**

**Резидентность данных (data residency)** — требование хранения данных в конкретном регионе/юрисдикции. Реализуется привязкой ячейки к региону. Разобрано: [21](21_TENANT_LIFECYCLE.md), 8. **[план]**

**Юридическое удержание (legal hold)** — запрет удаления данных, попавших в спор, поверх ретеншена. Разобрано: [21](21_TENANT_LIFECYCLE.md), 9.6. **[план]**

**Ретеншен (retention)** — автоудаление устаревших данных: события (`drop_chunks`), архив (по сроку и свободному месту). `api/src/retention.ts`. Разобрано: [10](10_DATABASE.md). **[есть]**

**SLI (индикатор уровня обслуживания)** — измерение того, что чувствует клиент (доля событий в БД). Разобрано: [22](22_SRE_OPERATIONS.md), 3. **[план]**

**SLO (цель уровня обслуживания)** — внутренняя цель по SLI. Всегда строже SLA. **[план]**

**SLA (соглашение об уровне обслуживания)** — договорное обязательство перед клиентом с компенсацией. Разобрано: [22](22_SRE_OPERATIONS.md), [11](11_HIGH_AVAILABILITY.md), 8. **[план]**

**Бюджет ошибок (error budget)** — допустимое количество отказов (1 − SLO). Исчерпан → заморозка функций. Разобрано: [22](22_SRE_OPERATIONS.md), 4. **[план]**

**Скорость выгорания (burn rate)** — темп расхода бюджета ошибок; основа оповещений. Разобрано: [22](22_SRE_OPERATIONS.md), 5.2. **[план]**

**Ранбук (runbook)** — инструкция по реагированию на конкретное оповещение, включая «что НЕ делать». Разобрано: [22](22_SRE_OPERATIONS.md), 7. **[план]**

**Разбор (postmortem)** — безобвинительный анализ инцидента. Разобрано: [22](22_SRE_OPERATIONS.md), 9. **[план]**

**Toil** — ручная повторяющаяся автоматизируемая работа, растущая с числом клиентов. Разобрано: [22](22_SRE_OPERATIONS.md), 12. **[план]**

**Учения (game day)** — плановая проверка процедуры восстановления. Разобрано: [22](22_SRE_OPERATIONS.md), 10. **[план]**

**Хаос-инжиниринг** — намеренное внесение отказов для проверки устойчивости. Не раньше ячеек. **[план]**

## 6. Сеть

**AmneziaWG** — обфусцированный WireGuard, обходящий DPI провайдера. Параметры обфускации (`Jc`, `Jmin`, `S1..S4`, `H1..H4`) едины на всех пирах. Разобрано: [04](04_NETWORK.md), 3. **[есть]**

**Хаб (hub)** — центральный узел AmneziaWG на VPS (`10.9.0.1`), маршрутизирующий между пирами. Разобрано: [04](04_NETWORK.md). **[есть]**

**Шлюз точки (gateway)** — устройство на площадке (ПК точки), пробрасывающее RTSP камер в туннель через `netsh portproxy`. Разобрано: [04](04_NETWORK.md), 5; [24](24_EDGE_FLEET.md). **[есть]**

**Split tunnel** — режим VPN, где через туннель идёт только подсеть платформы (`AllowedIPs = 10.9.0.0/24`), а интернет клиента — напрямую. Разобрано: [04](04_NETWORK.md), 3.5. **[есть]**

**Проброс (portproxy)** — перенаправление TCP-порта на шлюзе (`netsh interface portproxy`). Порт на камеру. **[есть]**

**Subflow / субпоток** — низкобитрейтный поток камеры (`url_sub`) для ИИ и живого видео. Основной поток (`url_main`) — для архива. Разобрано: [05](05_CAMERA_CONNECTION.md), 2. **[есть]**

**Edge-узел** — устройство на площадке, несущее аналитику (не только проброс). Разобрано: [24](24_EDGE_FLEET.md), 8. **[план]**

**Forwarder** — сервис, пересылающий события с площадки (edge/гибрид) в облачную ячейку с буферизацией. Разобрано: [24](24_EDGE_FLEET.md), 8.4. **[план]**

## 7. Безопасность и приватность

**Privacy-маска** — область кадра, исключённая из обработки (окно, чужая территория). Отсутствует. Разобрано: [13](13_SECURITY.md). **[план]**

**Цепочка владения (chain of custody)** — прослеживаемая история доказательства (клипа): хеш, подпись, журнал выгрузок. Разобрано: [13](13_SECURITY.md), [15](15_PVZ_MODULES.md). **[план]**

**Face-ID сотрудников** — распознавание лиц, применяемое **только к сотрудникам** с их ведома (YuNet + SFace). Посетители — никогда. Разобрано: [06](06_AI_ENGINE.md), 6. **[есть]**

**ПДн (персональные данные)** — данные, позволяющие идентифицировать субъекта. `global_id` анонимен; связка `global_id ↔ личность` — ПДн. Биометрия — особая категория (152-ФЗ). Разобрано: [13](13_SECURITY.md), [00](00_VISION.md), 7.1. **[есть]**

**RBAC** — управление доступом на основе ролей (`super`, `admin`, `manager`, `operator`). Разобрано: [13](13_SECURITY.md), 5. **[есть]**

**ABAC** — управление доступом на основе атрибутов (например, `allowed_camera_ids`). Разобрано: [13](13_SECURITY.md). **[частично]**

**token_version** — счётчик для отзыва JWT (инкремент инвалидирует выданные токены). Разобрано: [13](13_SECURITY.md), 4.3; [23](23_ENTERPRISE_INTEGRATION.md), 3.4. **[план]**

**SBOM (спецификация состава ПО)** — перечень компонентов и зависимостей образа для аудита уязвимостей. Разобрано: [13](13_SECURITY.md), [19](19_BEST_PRACTICES.md). **[план]**

**mTLS** — взаимная TLS-аутентификация между сервисами. Разобрано: [13](13_SECURITY.md), 9. **[план]**

**IEC 62443** — стандарт кибербезопасности промышленных систем. Разобрано: [13](13_SECURITY.md), [14](14_FACTORY_MODULES.md). **[план]**

## 8. Промышленность и интеграции

**OPC UA (IEC 62541)** — промышленный стандарт чтения состояния оборудования. Платформа — клиент только на чтение. Разобрано: [23](23_ENTERPRISE_INTEGRATION.md), 5; [14](14_FACTORY_MODULES.md). **[план]**

**MQTT / Sparkplug B** — протокол IIoT-телеметрии (публикация-подписка). Разобрано: [23](23_ENTERPRISE_INTEGRATION.md), 5.4. **[план]**

**ONVIF** — стандарт взаимодействия с IP-камерами. Profile S (видео), G (запись), M (метаданные/аналитика), T (H.265). Разобрано: [05](05_CAMERA_CONNECTION.md), 5. **[план]**

**СКУД** — система контроля и управления доступом. Даёт достоверную идентификацию работника по пропуску, снимая ограничение Re-ID на производстве. Разобрано: [23](23_ENTERPRISE_INTEGRATION.md), 8.2; [14](14_FACTORY_MODULES.md). **[план]**

**SIEM** — система управления событиями безопасности (KUMA, Splunk, Sentinel). Приём через CEF/syslog. Разобрано: [23](23_ENTERPRISE_INTEGRATION.md), 4. **[план]**

**SCIM** — протокол провижининга пользователей из корпоративного каталога. Разобрано: [23](23_ENTERPRISE_INTEGRATION.md), 3.4. **[план]**

**OIDC** — протокол аутентификации поверх OAuth 2.0 (Entra ID, Яндекс ID). Разобрано: [23](23_ENTERPRISE_INTEGRATION.md), 3. **[план]**

**Модель А / Модель Б** — стратегии выхода на рынок: А — замена VMS (ПВЗ); Б — аналитика как дополнение к существующей VMS (производство). Разобрано: [23](23_ENTERPRISE_INTEGRATION.md), 6. **[план]**

**OEE** — общая эффективность оборудования. Платформа даёт вход (простои по видео), не претендует на полный расчёт. Разобрано: [14](14_FACTORY_MODULES.md). **[план]**

**SIL** — уровень полноты безопасности (функциональная безопасность). Платформа **не** является системой SIL: вероятностная модель не останавливает оборудование. Разобрано: [14](14_FACTORY_MODULES.md), [04](04_NETWORK.md), 11.3. **[граница]**

## 9. Развёртывание

**Режим развёртывания (DEPLOYMENT_MODE)** — `cloud` или `on-premise`. Один код, различие в конфигурации (V-01). Разобрано: [00](00_VISION.md), 6.1; [03](03_DEPLOYMENT.md). **[есть]**

**On-premise** — развёртывание в периметре заказчика, изолированно. Разобрано: [03](03_DEPLOYMENT.md). **[архитектурно есть]**

**Гибрид (hybrid)** — обработка на площадке, агрегация событий в облаке. Разобрано: [03](03_DEPLOYMENT.md), 8. **[план]**

**Air-gap** — полностью изолированный контур без исходящего интернета. Разобрано: [03](03_DEPLOYMENT.md), 7.2; [24](24_EDGE_FLEET.md), 8.6. **[план]**

**Version skew** — одновременная работа разных версий ПО (ячейки при поэтапном выкате; сервер и старые on-prem). Разобрано: [03](03_DEPLOYMENT.md), [20](20_SCALE_ARCHITECTURE.md), 9.2. **[план]**

**Расширить — переключить — сузить** — паттерн безопасной миграции схемы (expand-migrate-contract). Обязателен при version skew. Разобрано: [03](03_DEPLOYMENT.md), 4.4. **[частично]**

**LTS** — версия с длительной поддержкой для промышленного заказчика. Разобрано: [14](14_FACTORY_MODULES.md); [03](03_DEPLOYMENT.md). **[план]**

**Феатур-флаг** — переключатель функции, отделяющий выкат кода от включения функции. Разобрано: [03](03_DEPLOYMENT.md). **[план]**

**Ячейка-канарейка** — ячейка с внутренними тенантами для проверки выката перед клиентами. Разобрано: [20](20_SCALE_ARCHITECTURE.md), [22](22_SRE_OPERATIONS.md). **[план]**

## 10. Данные

**TimescaleDB** — расширение PostgreSQL для временных рядов. `event`, `audit_log` — гипертаблицы. Разобрано: [10](10_DATABASE.md). **[есть]**

**Гипертаблица (hypertable)** — таблица, автоматически партиционированная по времени (чанки). PK включает колонку партиционирования — поэтому FK на `event.id` невозможен. Разобрано: [10](10_DATABASE.md). **[есть]**

**Чанк (chunk)** — партиция гипертаблицы по времени. `drop_chunks` удаляет старые целиком (быстрее DELETE). **[есть]**

**Компрессия** — сжатие чанков старше 7 дней (`add_compression_policy`). Разобрано: [10](10_DATABASE.md). **[есть]**

**meta (jsonb)** — типоспецифичные поля события без изменения схемы. Точка расширения. Разобрано: [01](01_SYSTEM_ARCHITECTURE.md), 9.3. **[есть]**

**MinIO** — S3-совместимое хранилище (клипы, снапшоты, кропы Re-ID). Разобрано: [01](01_SYSTEM_ARCHITECTURE.md). **[есть]**

**Presigned URL** — временная ссылка на объект MinIO, открываемая браузером напрямую. Требует `MINIO_PUBLIC_ENDPOINT`. **[есть]**

**Колоночное хранилище** — БД для кросс-ячеистой аналитики (ClickHouse). Область DB-01 уточнена: Timescale в ячейке, колоночное в control plane. Разобрано: [20](20_SCALE_ARCHITECTURE.md), 9.3. **[план]**

**CDC (захват изменений данных)** — поток изменений из БД ячеек в аналитическое хранилище. **[план]**

## 11. Наблюдаемость

**Метрика (metric)** — числовой временной ряд (Prometheus). `viziai_*`. Разобрано: [12](12_MONITORING.md). **[план]**

**Кардинальность** — число уникальных комбинаций меток метрики. `camera_id` как метка при 5000 камер взрывает кардинальность. Разобрано: [12](12_MONITORING.md), 5.1. **[план]**

**Трейс (trace)** — путь запроса через сервисы (OpenTelemetry, Tempo). **[план]**

**e2e-задержка** — время от события в реальности до его появления в ленте/БД. SLI-2. **[план]**

**Blackbox-проба** — проверка доступности снаружи (как клиент). **[план]**

**Thanos / Mimir** — долгосрочное хранение метрик Prometheus при планке. Разобрано: [12](12_MONITORING.md). **[план]**

## 12. Реестр решений и статусы

**Реестр решений** — таблица в конце каждого документа: решение, обоснование, отвергнутая альтернатива. Защита от «улучшения» решения обратно в проблему.

**ADR (запись архитектурного решения)** — формат решения со статусом (действует/заменено/отменено), датой, автором. Целевой формат реестров. Разобрано: [19](19_BEST_PRACTICES.md). **[план]**

**Реестр долга** — таблица известных проблем документа с приоритетом. Долг виден и имеет владельца.

**Триггер внедрения** — условие (не дата), при котором элемент проекта следует реализовывать. «Внедрять по триггеру, не по графику». Разобрано: [20](20_SCALE_ARCHITECTURE.md), 10. **[принцип]**

**Статусные пометки** — `[есть]` / `[План]` / `[Требует решения]` / `[Данные отсутствуют]`. Отличают факт от намерения. Обязательны во всём корпусе.
