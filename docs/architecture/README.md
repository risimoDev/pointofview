## Что требует действий

Полные списки — в разделе «Долг» каждого документа. Сводка критического — [18_ROADMAP.md](18_ROADMAP.md), 8.2.

| Находка | Документ |
|---|---|
| Приватные ключи AmneziaWG в репозитории и в истории Git | [13](13_SECURITY.md), S-01 · [04](04_NETWORK.md), 4 |
| Пароли камер отдаются любому пользователю через `GET /cameras` | [13](13_SECURITY.md), S-02 |
| JWT без срока действия; удаление пользователя не отзывает доступ | [13](13_SECURITY.md), S-03 |
| Нет ограничения частоты на `/login` | [13](13_SECURITY.md), S-04 |
| Резервных копий нет; отказ диска = безвозвратная потеря | [02](02_INFRASTRUCTURE.md), I-01 |
| Отказ PostgreSQL отправляет события в dead-letter, а не в повтор | [11](11_HIGH_AVAILABILITY.md), HA-D-02 |
| Нет метрик: юнит-экономика, ёмкость и SLA — догадки | [12](12_MONITORING.md), M-D-01 |
| Drizzle-мигратор тихо не работает (каталога миграций нет) | [10](10_DATABASE.md), 12.2 |

**Блокеры и критические находки планки 1000+** (по [REVIEW_BOARD.md](REVIEW_BOARD.md)):

## Соглашения

**Пометки**

| Пометка | Значение |
|---|---|
| `[План]` | Спроектировано, не реализовано |
| `[Требует решения]` | Решение не принято; приведены варианты и рекомендация |
| `[Данные отсутствуют]` | Факта нет в репозитории; объяснено, что нужно и почему |
| `[Требует проверки]` | Утверждение выведено из кода, не проверено на практике |

**Структура документа**

Статус и аудитория → назначение → фактическое состояние → анализ → **реестр решений** → **реестр долга**.

*Реестр решений* — таблица «решение / обоснование / отвергнутая альтернатива». Третий столбец обязателен: без него решение будет «улучшено» обратно в ошибку.

*Реестр долга* — таблица «проблема / влияние / приоритет». Закрытый пункт удаляется: реестр с закрытыми пунктами теряет доверие целиком.

**Стиль**

Русский язык; техническая проза без маркетинга и эмодзи; Mermaid для диаграмм; ссылки на код в формате `путь/файл.ext` с указанием функции.
